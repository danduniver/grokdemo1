# grokdemo1

A demo project for working with Grok (xAI) as a software engineering assistant.

This project serves as a sandbox for experimenting with Grok's capabilities: code generation, refactoring, debugging, project scaffolding, GitHub integration, skills, and more.

## Getting Started

1. Clone or open this folder in your environment where Grok CLI is available.
2. Run `grok` (or the TUI) inside this directory to start collaborating.
3. Grok will automatically pick up project rules from `AGENTS.md`.

## Project Structure

```
grokdemo1/
├── README.md
├── AGENTS.md
├── .gitignore
├── package.json
├── index.html          # Interactive browser demo
├── index.js            # Zero-dep Node demo server (npm start)
├── demo.js             # JS demo script (npm run demo)
└── demo.py             # Python demo script
```
